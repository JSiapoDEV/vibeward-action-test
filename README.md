# vibeward-action-test

A deliberately insecure throwaway app, used to test the
[vibeward](https://github.com/JSiapoDEV/vibeward) GitHub Action end to end:
the run summary, the pending-items issue and the SARIF upload.

Nothing here is deployed and nothing here holds a real key.

Runs: see the Actions tab.
The local action under .github/actions/ is vibeward 0.8.4 before its tag.
